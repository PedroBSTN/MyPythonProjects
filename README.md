# Meus projetos em Python

Aqui estão alguns dos meus projetos em Python, feitos no meu tempo livre para estudar e praticar.

## Como rodar

1. Instale o Python 3.
2. Clone o repositório: `git clone URL-DO-REPOSITORIO`
3. Execute um projeto: `python nome-do-arquivo.py`
